# What if you had a shark's teeth? (18.4 s)

Owl formula, animal-powers series. Scene: `src/Shark.tsx` (all code-drawn; guy body = library sprites, head + shark teeth in code;
the body leans with the head on a bite so the sprite head never peeks out).
Voice: James, eleven_v4, one take -> `scripts/tighten.py --tempo 1.12` -> `public/shark/vo/tight.mp3` (words from Scribe).
No new sounds (crack = crunch, twang = boing, whir = conveyor).
Render: `node scripts/render.mjs Shark renders/shark-1080x1920.mp4 1`; thumbnails: `COMP=ThumbTall SCALE=1 node scripts/stills.mjs --bundle 0`.
Facts: shark teeth are held by soft tissue on the jaw cartilage, not set in bony sockets, and are replaced row by row for life
(conveyor-belt replacement); young lemon sharks shed the outer row on a ~14-day cycle (tetracycline labelling study,
J. Dental Research 1970); measured replacement rates in sharks range from about 9 to 36 days per row. Humans: 2 sets (20 baby + 32 adult).
Lifetime totals (20,000-50,000 teeth) only show up in press write-ups, so they are left out.
